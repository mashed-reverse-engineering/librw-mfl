- API: `TexDictionary::readPI(const uint8 *data, uint32 size)` (complete chunk incl. 12 byte header, whole buffer must be consumed) and `TexDictionary::streamReadPI(Stream*)` (stream at the chunk header, consumes exactly the chunk). - Hardening: all reads bounds checked, chunk sizes must add up exactly, dims <= 8192, <= 16 levels, stride >= row bytes, per-image size recomputed.

- Test: `[SAN=1] tests/build_pitxd_test.sh [outdir]` then `pitxd_test [--fuzz N] FILES...`. Uses an in-memory raster driver installed on the null platform (mimics d3d lock semantics) and an independent re-walk of each file to compare names, flags, dims, formats, mip flags, palettes and every pixel of every level. Result on all 139 .TXD/.CMP files under MashedGame: 103 are PI (incl. the .CMP; 82 stamp 1C02000A, 20 stamp 1803FFFF, 1 cmp) = 103/103 PASS, 36 are native PS2/Xbox (chunk 0x16) and are skipped (use TexDictionary::streamRead). ## Collision (RpCollision pieces the game uses) - third clean-room gap, status 2026-10-19
Written only from MashedFormats/FORMATS.md + rwscene.py `read_colltree` + the shipped data + the game's import list (ghidra/output/rwsurf/api_used.csv, names only; the SDK sources/headers were NOT read). Patch: patches/0014-collision-tree-and-queries.patch (git commit not done: policy; review fixes in 0017, see below). New files src/collision.cpp, src/rwcollision.h, tests/collision_test.cpp, tests/build_collision_test.sh; hunks in rw.h (include), src/CMakeLists.txt, rwobjects.h (`WorldSector::collTree`), world.cpp (parse after the raw blob read, free in destroyNode, include). Independent of rendering.
- Tree format (verified on all 217 sector trees of the 126 BSPs, flags is always 1 = has map): blob = u32 0x37002 + chunk 0x2C { STRUCT { flags, bbox inf/sup, numEntries (= sector triangle count), numSplits, numSplits x {left, right}, u16 map[numEntries] } }. Node = {u8 type, u8 contents, u16 index, f32 value}; type bits 2..3 axis (0 x, 4 y, 8 z), bit 0 set = "left" node: its triangles have coordinate <= value (value = max of its triangles), bit 0 clear = "right" node: coordinate >= value (value = min). contents 0xFF = split, index = splits[] entry (root = splits[0], which is a pair, there is no separate root node); otherwise a leaf with `contents` entries (1..12 in the data, mostly 2) at map[index..index+contents). Child volumes overlap, every triangle is in exactly ONE leaf (map is a permutation). Tree bbox == sector tight bbox. The stored values are exact only to ~1 ulp (max overshoot of a triangle vertex over its leaf volume 9.5e-7), so traversal uses a 1e-5 relative slack. Max depth 28 in the data.
- API (rwcollision.h, namespace rw): `CollisionTree::fromBlob/toBlob/blobSize/clone/destroy/build`, `collisionWorldSectorQueryData/DestroyData`, `collisionWorldForAllIntersections`, geometry plugin 0x11D (`registerCollisionPlugin`, `collisionGeometryBuildData/QueryData/DestroyData/ForAllIntersections`, stream read/write/copy), `collisionAtomicForAllIntersections`, `collisionBuildParamInitDefaults`, `intersectionLineTriangle` (RtIntersectionLineTriangle), `lineSphereIntersectionTest` (RtLineSphereIntersectionTest), `baryGetTransform` (RtBaryGetTransform). Types `Intersection` (line/sphere/box + type), `CollisionTriangle` {normal, point, index, vertices[3]}, callbacks return nil to stop. The loader (`World::streamRead`) now rejects a sector whose tree does not parse (strict: sizes, entry/split ranges, tree shape, depth <= 512, entries == triangles). No DFF in the game data has a geometry 0x11D (checked all 1389), so the geometry side is only exercised by the tests (the game calls GeometryBuildData at load time on vehicle geometries, see vehicle_load).
- [SUPERSEDED by 0017, see "Collision review fixes"] Query semantics (see unknowns below): line = segment start..end, two sided, distance = fraction in [0,1]; sphere: closest triangle point within radius, distance = |center - closest point|, point = closest point; box (AABB): triangle/box SAT overlap (touching counts), distance/point as sphere with the box centre. Sectors are visited in stream order, culled by the sector tight bbox; inside a sector kd traversal left then right; sectors without a tree are tested triangle by triangle. Each triangle reported at most once.
- Test: `[SAN=1] tests/build_collision_test.sh [outdir]` then `collision_test [-n queriesPerFile] [-g] FILES...`. Per file: world load, every stored tree validated (indices, leaf volumes, every triangle exactly once, splits reachable once, map permutation, tree bbox = sector bbox) and re-serialised byte-exact (stamps masked); trees rebuilt with `CollisionTree::build` (leaf 1/2/5) validated + blob roundtrip + clone; random line/sphere/box queries (70% anchored on a random triangle, log-uniform sizes, axis aligned lines) compared with an independent double precision brute force (plane+barycentric line test, clipping box test, region based sphere distance; boundary cases within 1e-5 are counted as ambiguous and accepted either way); sector order, callback arguments (vertex pointers, unit normal, point), early stop; no-tree fallback; geometry plugin (build, query vs brute force, atomic path with an exact (axis permutation, scale 2) frame vs the local query, lines and spheres); parser fuzz (150 truncations/bit flips per tree on 3 trees per file, survivors are queried). Hand computed unit checks for the Rt functions. Mutating the traversal (left/right bound swapped) fails 16565 checks, so the cross-check does bite.
- Result: 126 files, 1080 sectors (217 with tree), 727168 triangles; 454800 world queries (151728 line, 151536 sphere, 151536 box; ~75% with hits, 56.6M hit triangles) 0 mismatches, 0 bad distances, 13799 ambiguous boundary cases; 1929 rebuilt trees, 192 geometry plugin runs, 23400 fuzz mutations (5220 still parsed and were queried); ASan+UBSan (SAN=1, -n 3000, 10 min): same numbers, PASS, no sanitizer reports. tests/bsp_test still 126/126. (Atomic path: Matrix::invert() picks invertOrthonormal from stale flags after a scale, so collisionAtomicForAllIntersections uses invertGeneral.)
